# Участие в разработке

Спасибо за интерес к DocuFlow.

## Как предложить изменение

1. Создайте fork репозитория.
2. Создайте отдельную ветку от `main`.
3. Внесите небольшое, связанное изменение.
4. Запустите тесты и проверку зависимостей.
5. Создайте pull request с понятным описанием результата.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip check
```

## Правила

- не добавляйте `.env`, базы данных и пользовательские документы;
- для нового поведения добавляйте функциональный тест;
- сохраняйте совместимость с Python 3.11+;
- не отключайте CSRF, проверку владельца и валидацию файлов;
- пользовательские сообщения должны оставаться понятными без технического жаргона.
