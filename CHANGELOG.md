# История изменений

Все заметные изменения DocuFlow фиксируются в этом файле.

## 2.0.0 — 2026-09-06

### Добавлено

- новая адаптивная дизайн-система со светлой и тёмной темами;
- личный кабинет и пользовательские настройки;
- отдельная админ-страница каждого пользователя;
- роли, блокировка аккаунтов и индивидуальные квоты;
- папки, теги, избранное, корзина и массовые действия;
- склейка PDF с управлением порядком;
- извлечение нескольких диапазонов страниц;
- преобразование нескольких изображений в PDF;
- поворот, оптимизация, водяные знаки и нумерация страниц;
- расширенный аудит действий;
- запуск на Windows одним кликом;
- автоматическое обновление схемы SQLite и GitHub Actions.

### Безопасность

- проверка содержимого загружаемых файлов;
- CSRF-защита и защитные HTTP-заголовки;
- безопасные cookie и разграничение доступа по владельцу;
- защита от удаления последнего администратора.
