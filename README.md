DocuFlow — приватная библиотека документов и PDF Studio с личным кабинетом, расширенной админ-панелью и адаптивным интерфейсом. Приложение работает на русском, казахском и английском языках.

> Все документы обрабатываются локально на вашем компьютере или сервере. DocuFlow не отправляет их во внешние сервисы.

## Получение проекта

Скачайте репозиторий через **Code → Download ZIP** или клонируйте его:

```powershell
git clone https://github.com/Araaset/DocuFlow.git
cd DocuFlow
```

## Возможности

### Библиотека

- загрузка PDF, DOCX, PNG и JPG до 50 МБ через выбор файла или drag-and-drop;
- проверка реального содержимого файла, подсчёт SHA-256 и защита от дублей;
- полнотекстовый поиск по PDF/DOCX, фильтры по типу, папке и избранному;
- папки, теги, переименование, избранное и массовые действия;
- безопасный предпросмотр и скачивание;
- корзина с восстановлением и окончательным удалением;
- персональная квота хранилища.

### PDF Studio

1. Склейка до 20 PDF с перетаскиванием файлов в нужном порядке.
2. Извлечение нескольких диапазонов: `1-3, 5, 8-10`.
3. Сборка одного PDF из нескольких PNG/JPG, в исходном размере или A4.
4. Поворот всех страниц на 90°, 180° или 270°.
5. Оптимизация структуры и повторяющихся объектов PDF.
6. Unicode-водяной знак и автоматическая нумерация страниц.

Все результаты автоматически сохраняются в библиотеке, а исходники остаются неизменными.

### Личный кабинет и администрирование

- профиль, имя, email, язык, тема, компактный режим и уведомления;
- смена пароля и просмотр использования хранилища;
- админ-панель со статистикой и поиском пользователей;
- отдельная страница каждого пользователя: документы, место, последние действия, IP и браузер;
- изменение роли, статуса и квоты пользователя;
- защита от блокировки собственной учётной записи и удаления последнего администратора.

## Быстрый запуск на Windows

Нужен Python 3.11 или новее.

### Запуск в один клик

Распакуйте ZIP и дважды нажмите **`Запустить DocuFlow.bat`**. При первом запуске программа сама создаст окружение и установит необходимые компоненты, затем автоматически откроет сайт в браузере. В дальнейшем достаточно снова нажимать этот файл. Чтобы остановить локальный сайт, закройте окно DocuFlow.

### Ручной запуск

```powershell
cd "путь\к\DocuFlow"
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python app.py
```

Откройте [http://127.0.0.1:5000](http://127.0.0.1:5000). При первом запуске автоматически создаётся локальная SQLite-база `docuflow.db`.

Если PowerShell запрещает активацию окружения, можно запускать без активации:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

## Создание администратора

Закройте запущенный сервер, затем выполните:

```powershell
$env:ADMIN_EMAIL="admin@example.com"
$env:ADMIN_PASSWORD="use-a-strong-password"
.\.venv\Scripts\flask.exe --app app init-db
```

После входа админ-панель появится в левом меню. Прямой адрес: `http://127.0.0.1:5000/admin`.

## Конфигурация и безопасность

Скопируйте `.env.example` в `.env` и обязательно задайте длинный случайный `SECRET_KEY`. Для MySQL укажите `DATABASE_URL` и предварительно выполните `schema.sql`.

При запуске с SQLite приложение автоматически и без удаления данных добавляет новые поля старой версии. Для рабочей MySQL-инсталляции изменения схемы следует проводить отдельной миграцией перед обновлением.

Для HTTPS включите `SESSION_COOKIE_SECURE=true`. Никогда не публикуйте `.env`, `docuflow.db` и содержимое `uploads/`.

В приложении включены CSRF-защита, безопасные cookie, ограничение доступа по владельцу, защитные HTTP-заголовки, проверка формата файлов и аудит операций.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe -m pip check
```

Тесты покрывают регистрацию, безопасность, изоляцию пользователей, библиотеку, папки/теги/избранное, корзину, массовые действия, шесть PDF-инструментов и администрирование.

При каждом push и pull request те же тесты автоматически запускаются в GitHub Actions на поддерживаемых версиях Python.

## Структура

```text
DocuFlow/
├── app.py             # фабрика приложения, схема SQLite и безопасность
├── auth.py            # регистрация, вход и статус пользователя
├── main.py            # библиотека, профиль, PDF Studio и админка
├── services.py        # обработка PDF, DOCX и изображений
├── models.py          # модели пользователей, документов и аудита
├── templates/         # страницы Jinja
├── static/            # дизайн-система, анимации и JavaScript
└── tests/             # функциональные тесты
```
